# Telegram бот: каталог + трейд-ин + выкуп + админка

Бот делает то, что вы запросили:
- каталог с выбором `категория -> марка -> модель -> память -> страна`
- заявка на покупку товара (без оплаты в боте)
- трейд-ин (обмен с предложением цены)
- выкуп устройства (предложение цены)
- после заявки клиенту отправляется: **"С Вами сейчас свяжется менеджер"**
- все лиды уходят в отдельный Telegram-чат (через `LEADS_CHAT_ID`)
- каждый лид отслеживается и получает продающие триггеры
- админка для управления товарами, ценами, заявками, лидами и чатами

## 1) Настройка

Скопируйте `.env.example` в `.env` и заполните:

```env
BOT_TOKEN=...
ADMIN_PASSWORD=...
ADMIN_PORT=3000
SESSION_SECRET=...
LEADS_CHAT_ID=123456789
ADMIN_CHAT_IDS=123456789,987654321
DATA_FILE=./data/db.json
```

Важно:
- `LEADS_CHAT_ID` — отдельный чат для всех заявок (лидов)
- бот должен быть добавлен в этот чат
- если чат приватный, отключите Privacy Mode у бота через BotFather

## 2) Запуск через docker-compose

```bash
docker compose up -d --build
```

Проверка логов:

```bash
docker compose logs -f bot
```

Остановка:

```bash
docker compose down
```

## 3) Админ-панель

Откройте:

```text
http://localhost:3000/login
```

В админке доступны разделы:
- `Товары` — добавить/изменить/удалить товары и цены
- `Покупки` — заявки на покупку
- `Трейд-ин/Выкуп` — заявки на обмен и выкуп
- `Лиды` — статусы лидов + трекинг триггеров
- `Чаты` — история сообщений с клиентами + ответ клиенту

## 4) Продающие триггеры (авто)

Для лидов со статусом `new/in_progress` бот отправляет follow-up сообщения:
- через 5 минут
- через 1 час
- через 24 часа

Стадия триггера хранится в базе `data/db.json`.

## 5) Меню бота

Кнопки:
- `📦 Каталог`
- `🔁 Трейд-ин`
- `💰 Продать устройство`
- `📋 Мои заявки`
- `ℹ️ Инфо`

## Структура

- `src/bot.js` — Telegram логика, заявки, лиды, триггеры
- `src/admin.js` — веб-админка
- `src/store.js` — JSON-хранилище
- `src/index.js` — запуск бота и панели
- `docker-compose.yml` — контейнерный запуск
